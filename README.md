# SProfile Editor

Веб-апка для Steam-профілю: завантажуєш фон (GIF / PNG / JPG) — він лягає на макет профілю, а
панелі вітрини (Featured Artwork, Artwork Showcase) автоматично вирізаються з тих місць фону, над
якими стоять, щоб на профілі все виглядало одним полотном. Клік по панелі відкриває попап: скачати
файл, поставити в слот свій файл замість фону або дотиснути файл під ліміт Steam 5 МБ.

Усе працює в браузері — файли нікуди не вантажаться.

## Запуск

```bash
npm install
npm run dev     # http://localhost:3000
npm run lint
npm run build
```

## Як це влаштовано

```
src/
  app/                 Next.js app router: layout, сторінка, глобальні стилі (палітра — токени в globals.css)
  components/          UI: Editor збирає все докупи; ProfilePreview — макет профілю, PanelDialog — попап слота
  hooks/
    useSource.ts       завантажене джерело + його preview URL
    useSlices.ts       нарізані файли (переріз лише змінених слотів), оптимізація, blob URL
    useOverrides.ts    свої файли в окремих слотах (адреса слота = панель:позиція, переживає зміну типу)
  lib/
    steam/showcases.ts розміри слотів і ліміти Steam (джерела — docs/steam-specs.md)
    steam/profile.ts   геометрія сторінки профілю (ширина колонки, відступи — див. калібрування)
    steam/plan.ts      чиста математика: де стоїть кожна панель і який шматок фону під нею
    gif/info.ts        легкий парсер GIF (розмір, кадри, затримки) без декодування пікселів
    gif/gifsicle.ts    обгортка над gifsicle-wasm-browser
    image/decode.ts    читання метаданих джерела
    image/slice.ts     нарізка: canvas для статики, gifsicle для GIF (паралельно по слотах)
    optimize/image.ts  стиснення картинок: PNG → JPEG з підбором якості
    optimize/          оптимізатор GIF
    i18n/              переклади (en — дефолт, uk, nl); тип Messages у types.ts не дасть забути ключ
```

## Оптимізатор GIF

Налаштування — в блоці «Оптимізатор GIF» над результатами.

- **Авто** — задаєш ліміт (за замовчуванням 5 МБ) і що можна жертвувати: lossy, палітру,
  кадри. Спершу пробується стиснення без втрат, далі драбинка від найменш помітних втрат до
  найбільш (`AUTO_MOVES` у `lib/optimize/settings.ts`). Потрібний щабель шукається стрибками +
  бінарним пошуком, тож це 1–8 проходів gifsicle замість перебору всіх 14.
- **Вручну** — lossy, кількість кольорів, проріджування кадрів і роздільність застосовуються
  рівно як виставлено.

Оптимізація завжди стартує з оригінальної нарізки, а не з попереднього результату, тому
налаштування можна крутити й перезапускати без накопичення втрат. При проріджуванні кадрів
затримки викинутих кадрів додаються до залишених — тривалість анімації не міняється.

## Калібрування

Геометрія профілю (`lib/steam/profile.ts`) заміряна на збереженій сторінці живого профілю, а тест
звіряє з нею план до пікселя. Теми профілю можуть відрізнятись — тоді підкрути відступи в блоці
«Калібрування під реальний профіль».
